# Hello Python 評估集與基準驗證 (Evals)

本目錄存放 `hello-python` 系統的提示詞評估集、輸出基準測試與質量防護網。

---

## 1. 評估維度與目標 (Evaluation Dimensions)

| 維度 | 驗證重點 | 驗收標準 |
| :--- | :--- | :--- |
| **功能正確性** | 巴斯卡三角形演算法計算 | 各階層數值正確，無越界或型別錯誤 |
| **視覺呈現** | 控制台文字格式化對齊 | 三角形金字塔居中對齊，等寬輸出 |
| **強健性** | 邊界輸入防護 (如 0, 負數, 極大值) | 優雅回傳或拋出清晰提示，無崩潰 |
| **隱私與安全** | 日誌輸出與 Commit 歷程 | 零真實姓名、零非安全郵箱洩漏 |

---
